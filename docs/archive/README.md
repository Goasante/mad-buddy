# Historical project records

This directory preserves old handoffs, audits and checkpoint documents for traceability.

These files are **not current product, release or operational authority**. Start with:

- `docs/operations/START-HERE.md`
- `docs/product/CONTINUATION.md`
- `docs/database-map.md`
- `docs/operations/PRODUCT-INVARIANTS.md`

Historical files remain useful for understanding why earlier decisions were made, but they should not be used to infer the current branch, production state, pricing model, migration state or release readiness.
